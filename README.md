# Blog شخصي

ابني مدونة شخصية editorial بالعربية: صفحة رئيسية بآخر 6 مقالات بصور كبيرة، صفحة كل المقالات مع pagination، صفحة مقال واحد بـ typography ممتاز ومحتوى 800+ كلمة، صفحة About الكاتب، Contact، اشتراك newsletter (احفظ في /api/data/subscribers). املأ /api/data/posts بـ 8 مقالات حقيقية متنوعة المواضيع. تصميم serif كلاسيكي + abundant whitespace.
